# 요구사항

## 목적

문서 기반 개발(Doc-Driven Development) 프로젝트에서 흩어진 문서를 찾고
기능의 상하위 구조를 파악할 수 있는 로컬 문서 지도를 제공한다.

현재 단계는 공개 프로젝트 부트스트랩이다. 기능 구현 상태는
[구현 계획](./IMPLEMENT.md), 기술 결정은 [설계](./DESIGN.md)를 기준으로 한다.

## 문서와 코드 위치

- 이 도구 자체의 기준 문서: 이 디렉터리의 4종 문서.
- 실행 진입점: ../bin/ddd-docmap.js.
- 구현 모듈: ../src/.
- 향후 테스트와 예제: 공개 가능한 가상 프로젝트를 사용한다.
- 대상 프로젝트의 문서는 원래 위치에서 읽으며 별도의 기준 사본을 만들지 않는다.

## 제약과 배포

- 공개 GitHub 저장소 생성과 npm 배포는 서로 다른 단계다.
- 현재 패키지는 private이며 라이선스와 배포 이름을 확정한 뒤 공개 배포를 검토한다.
- CLI 뼈대의 Node.js 최소 버전은 22로 둔다. 지원 OS와 최종 런타임 범위는 TBD다.
- 대상 프로젝트의 언어나 빌드 도구와 별도로 실행한다.
- 문서 본문은 로컬에서 처리한다. 외부 분석 서비스는 초기 범위에 포함하지 않는다.
- 패키지의 웹 화면은 미리 빌드해 포함하는 방식을 제안한다.
- 기존 프로젝트마다 4종 문서를 모두 새로 작성하도록 요구하지 않는다.

## 현재 범위 밖

문서 편집, 업무 진행률 판정, 중앙 문서 호스팅, 여러 저장소를 모은 조직 대시보드,
원격 저장소 동기화, AI 요약 서비스는 첫 버전의 범위 밖이다.
