# 수동 검증 체크리스트

아래 항목은 제품 인수 기준이며 현재 미실행이다.
부트스트랩의 CLI 검사 결과는 [구현 계획의 검증 이력](./IMPLEMENT.md#검증-이력)에 기록한다.

## 실행 기록 형식

각 검증에 날짜, OS·Node 버전, 설치한 패키지 버전/커밋, 대상 예제,
pass/fail/미실행과 관찰 결과를 남긴다. 미구현 기능은 pass로 기록하지 않는다.

| ID | 시나리오 | 통과 기준 | 상태 |
| --- | --- | --- | --- |
| M-01 | 기본 발견 | 설정 없이 docs 하위 문서와 docs 밖 표준 4종 문서를 발견하고 산출물·의존 패키지를 제외한다. | 미실행 |
| M-02 | 기능 묶음과 계층 | 상위 자체 문서, 하위 기능, 부분 4종, README 기반 공통 문서를 구분해 탐색한다. | 미실행 |
| M-03 | 카드 탐색 | 카드에 제목·설명이 보이고, 화살표와 카드 선택이 각각 하위 기능·문서 선택을 펼친다. 키보드로도 접근한다. | 미실행 |
| M-04 | 본문 읽기 | 표·코드·제목을 읽을 수 있고 선택한 문서가 분명하다. 문서 이동 후 지도 위치를 유지한다. | 미실행 |
| M-05 | 검색 | 기능명·원본 경로·본문으로 검색하고 소속과 일치 문맥에서 원하는 문서로 이동한다. | 미실행 |
| M-06 | 링크 | 상대 Markdown·앵커와 합의된 이미지·코드 링크가 원본 위치를 기준으로 동작한다. 뒤로 가기로 복귀한다. | 미실행 |

| M-12 | 지원 환경 | 명시한 최소 Node 버전·OS에서 실행과 종료를 확인하고 작은 화면·한글·공백 경로를 점검한다. | 미실행 |

## 릴리스 판정

- 필수 기준은 각 기능과 결정이 구현될 때 확정한다.
- 첫 제품 릴리스에서는 확정된 요구사항에 대응하는 항목을 모두 실행한다.
- 제안 요구사항을 제외하기로 결정하면 요구사항·설계·계획·이 체크리스트를 함께 갱신한다.
- public 저장소 생성만으로 제품 인수를 통과했다고 판단하지 않는다.
